# EcomDune

**EcomDune is Amazon seller analytics software** built to help Amazon sellers understand product profitability, keyword performance, indexing, and PPC data in one dashboard.

🌐 **Website:** https://ecomdune.com  
🚀 **App:** https://app.ecomdune.com

## What is EcomDune?

EcomDune provides analytics and insights for Amazon sellers across multiple Amazon marketplaces.

It brings important seller data together in one place so sellers can better understand the performance of their products, keywords, and advertising.

### Key capabilities

- Per-SKU net profit analytics
- Keyword rank tracking
- Indexing status monitoring
- PPC data and analytics
- Amazon marketplace analytics
- Amazon search result analysis through the **Market Scan** Chrome extension
- AI integrations through a read-only MCP connection

## Features

### 📊 Per-SKU Profit Analytics

EcomDune shows per-SKU net profit to help Amazon sellers understand the profitability of individual products.

### 🔎 Keyword Rank & Indexing

Track keyword performance and monitor indexing status to better understand how products are performing in Amazon search.

### 📈 PPC Analytics

EcomDune provides PPC data and analytics in one dashboard.

> EcomDune is an analytics tool. It does **not** change Amazon ad bids, budgets, or campaigns.

### 🌎 Amazon Marketplace Support

EcomDune supports Amazon sellers across multiple Amazon marketplaces.

The current list of supported marketplaces is maintained on the EcomDune website:

**https://ecomdune.com/about**

The supported marketplace list may expand over time.

### 🤖 AI & MCP Integrations

EcomDune connects to **Claude, ChatGPT, and Gemini** through a **read-only MCP connection**.

### 🧩 Market Scan Chrome Extension

EcomDune includes a Chrome extension called **Market Scan** that reads Amazon search results pages.

### 📥 Sellerboard Cost Import

EcomDune can import cost of goods files from **Sellerboard**.
